# Educator lesson refresh

**Situation:** An educator has a fictional lesson plan, learning goals, sample
materials, and a school accessibility checklist.

**Agent fit:** The agent can map goals to activities and checks, find gaps, and
prepare alternate representations. The educator judges subject accuracy,
student needs, and fairness.

**Task brief:**

> Create `lesson-alignment.md` showing each learning goal, learning activity,
> and evidence of understanding. Create `revision-draft.md` that adds choices
> for participation and more than one way to access key information. Use only
> the practice materials. Mark gaps instead of inventing school policy or
> student needs. Do not grade or identify students.

**Checks:** Every activity supports a stated goal; every goal has observable
evidence; added choices do not lower the learning goal; no student data
appears; the educator reviews accuracy and feasibility.

**Measure the gain:** Count alignment gaps found and changes the educator
accepts after review. Ask whether the map makes future revision easier.

**Safety boundary:** Student records, disability information, and graded work
require approved systems and policy. The agent should support, not make,
individual accommodation or grading decisions.
