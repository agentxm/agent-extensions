# Student study pack

**Situation:** A student has allowed lecture notes, a reading outline, and the
teacher's learning goals for an upcoming review.

**Agent fit:** The agent can organize material, create practice questions, and
compare answers with sources. The student must still retrieve, explain, and
apply the ideas.

**Task brief:**

> Create `study-map.md`, `practice-questions.md`, and
> `answer-check.md` from the allowed course files. Cover every learning goal.
> Put answers in a separate section so I can practice retrieval first. Point
> each answer to a source file and mark anything the notes do not support. Do
> not complete a graded assignment or add outside material.

**Checks:** Every goal appears; questions require more than copying a phrase;
answers are source-grounded; unsupported topics are marked; the student can
explain sampled answers without reading them.

**Measure the gain:** Use a short self-test before and after study. Measure
recall and explanation, not the number of pages generated.

**Safety boundary:** Follow the course's academic-integrity and AI-use rules.
Do not upload restricted class material or another student's work.
