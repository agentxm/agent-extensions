# How to start with your platform

1. Check whether your workplace, school, or professional setting has an
   approved product, account, or AI-use policy. Use that route when it exists.
2. Choose a form that matches your comfort: a graphical desktop app, an editor
   add-on, or a command-line tool. The 101 lesson works in any form that can
   read and create files in one folder.
3. Install or open the product from its official source. Confirm account,
   operating-system, and availability requirements in the current guide.
4. Review the product's data and permission settings. Know whether work runs
   locally, remotely, or in a mixture of both, and what may be retained.
5. Create a new practice folder containing only fictional exercise files.
6. Give the product access only to that folder when the interface allows it.
7. Begin with a read-only check: ask the agent to list visible files without
   changing them.
8. If it can see more than intended, stop and narrow the folder, account, tool,
   or permission before continuing.
9. Complete [Your first useful result](../101/your-first-useful-result.md).

If setup requires unfamiliar administrator access, software installation, or
security choices, use the provider's official support or a trusted local
administrator. Do not copy commands from an unverified source merely to get
past a blocker.
