# Desktop Agent 201

Manage reusable agent work that matters to more than one person, product, or
project. This path teaches the problems a shared workflow library or manager
must solve without prescribing a particular product.

## Learning path

1. [When a workflow needs management](when-a-workflow-needs-management.md) -
   Recognize the point where loose copies and memory stop being enough.
2. [Keep one main copy with an owner and history](keeping-one-main-copy.md) -
   Make the trusted source and responsibility clear.
3. [State requirements and portability](stating-requirements-and-portability.md)
   - Describe what the workflow needs and where it can run.
4. [Change, release, and retire safely](changing-releasing-and-retiring.md) -
   Test updates, communicate compatibility, and remove unsafe versions.
5. [201 capstone](capstone.md) - Repair a fictional shared-workflow breakdown
   and design a dependable operating model.

Complete 102 first, or bring a reusable workflow with evidence from at least
two different input sets.
