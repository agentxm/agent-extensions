# Plain-language standard

Write for a capable person who may be new to the tool and may be reading under
time pressure, stress, distraction, or cognitive load.

## Required patterns

- State the purpose and expected result near the top.
- Use familiar words and define a necessary new term on first use.
- Put one main action in each numbered step.
- Show what the learner should see after a step when silence would cause doubt.
- Give a recovery route for likely blockers.
- Keep critical paths short and move optional depth behind links.
- Do not require the learner to remember facts from several pages earlier.
- Use consistent names for the same object and action.
- Present examples before asking learners to generalize.
- Test with intended readers; an automated reading score is not proof of
  understanding.

## Preferred words

| Avoid or define | Prefer first |
| --- | --- |
| artifact | file, report, plan, or result |
| agentic workflow | task directed by an AI agent |
| autonomous | able to act without asking each time |
| context window | information the agent can consider now |
| canonical source | main maintained copy |
| provenance | where it came from and who produced it |
| deterministic | fixed rules with a predictable result |
| capability | something the agent is set up to do |
| orchestration | coordinating steps and tools |
| lifecycle | how something is created, maintained, updated, and retired |

Use a technical term when it helps the learner use the product or communicate
with others. Pair it with ordinary language: “main maintained copy (sometimes
called the canonical source).”

Avoid “simply,” “obviously,” “just,” unexplained initials, jokes that carry an
instruction, and language that treats confusion as a learner failure.

## Review with people

Ask representative readers to explain the task in their own words and attempt
it without coaching. Observe where they stop, guess, or take a risky action.
Revise the content, then test again. Preference questions alone do not show
whether the instructions work.
