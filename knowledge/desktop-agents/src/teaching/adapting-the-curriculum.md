# How to adapt the curriculum

Use the Knowledge bundle as the maintained source. A workshop, slide deck,
handout, learning system course, or role-specific quickstart is a route through
that source—not a second independent curriculum.

1. Name the new audience, setting, time available, and performance need.
2. Select outcome IDs from [Learning outcomes and
   evidence](learning-outcomes-and-evidence.md). State any outcomes you omit.
3. Choose only the concepts needed for those outcomes. Link back to their
   concept IDs or paths and record the bundle version.
4. Select or write a fictional scenario that resembles the audience's work.
   Preserve the same safety and verification demands.
5. Map each outcome to an activity and a piece of evidence. Remove content that
   has no role in that alignment.
6. Keep product setup in a separate, freshness-dated handout. Do not bury
   lasting concepts inside screenshots that will age quickly.
7. Test the derivative with representative learners and feed accepted
   corrections back to the main source before copying them elsewhere.

## Useful derivative shapes

- **30-minute executive briefing:** task fit, one demonstration, risk levels,
  and a next-task decision. Promise awareness and task selection, not mastery.
- **Two-hour 101 workshop:** full guided lesson plus a new task brief and
  permission decision.
- **Self-paced 101:** short pages, visible checkpoints, downloadable fictional
  inputs, and an exit performance.
- **Role quickstart:** shared 101 loop plus one persona scenario and its
  professional boundary.
- **102 lab:** workflow card, two input sets, failure case, and sharing
  decision.
- **201 working session:** diagnose an existing library, then use the capstone
  criteria to design its operating model.

Adapt examples, pace, and presentation. Do not lower the safety gate or replace
performance evidence with attendance.
