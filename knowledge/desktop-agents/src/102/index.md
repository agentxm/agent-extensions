# Desktop Agent 102

Turn a successful one-time task into a reusable method. This path introduces
saved instructions, templates, and “skills” without assuming a particular
product.

## Learning path

1. [Spot work worth repeating](spotting-work-worth-repeating.md) - Find the
   repeated explanation, handoff, or cleanup that creates friction.
2. [Build a reusable workflow](building-a-reusable-workflow.md) - Separate the
   stable method from the inputs that change each time.
3. [Inspect and run a sample workflow](inspecting-and-running-a-sample-workflow.md)
   - Practice with two fictional weeks and an unsafe instruction hidden in an
   input file.
4. [Adopt reusable instructions safely](adopting-reusable-instructions-safely.md)
   - Inspect an existing skill, template, or instruction set before use.
5. [Test a reusable workflow](testing-a-reusable-workflow.md) - Try normal,
   changed, and unsafe cases before trusting it.
6. [102 transfer challenge](transfer-challenge.md) - Run the method twice with
   different inputs and decide whether it is ready to share.

Complete [Desktop Agent 101](../101/) first, or show equivalent evidence: a
clear brief, bounded permissions, and a checked result.
