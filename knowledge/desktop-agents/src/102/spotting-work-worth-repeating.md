# How to spot work worth repeating

Review the last two weeks of work and look for these signals:

- You pasted the same background or rules into several chats.
- You copied an AI answer through the same cleanup steps each time.
- The result was good only after you remembered a hidden instruction.
- Several people perform the same task in slightly different ways.
- You regularly forget which source, format, or check to use.
- A useful prompt has become a long personal note that no one else can follow.

Choose one candidate and observe it twice before packaging it. Record:

1. What starts the work?
2. Which inputs change each time?
3. Which instructions remain stable?
4. What output is expected?
5. Which checks catch common mistakes?
6. Where must a person decide or approve?

Good 102 candidates recur, have a recognizable finish line, and benefit from
consistency. Examples include turning weekly notes into an update, preparing a
lesson handout, reviewing a folder for missing forms, or converting research
into a source table.

Do not package a workflow merely because it worked once. Avoid tasks that are
mostly unique judgment, depend on unapproved sensitive information, or change
so often that the instructions would be outdated before the next use.

The first benefit of reuse is not total automation. It is starting from a
known method instead of reconstructing the job from memory.
