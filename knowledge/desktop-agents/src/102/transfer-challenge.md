# Desktop Agent 102 transfer challenge

Create or adopt one reusable workflow and use it on two different input sets.

## Your challenge

1. Complete a workflow card with its trigger, changing inputs, stable steps,
   output, checks, limits, and owner.
2. Run it on one ordinary fictional or approved case.
3. Run it again with a meaningful change or missing input.
4. Compare the results. Record any instruction you had to repeat outside the
   workflow and any mistake a check caught.
5. Decide: keep it personal, revise and retest it, share it with a small group,
   or retire it.

## Passing evidence

You are ready for 201 when the workflow:

- starts in the intended situation and not in unrelated work;
- accepts new inputs without carrying over old names or dates;
- produces a consistent, checkable result;
- stops or asks when an important input is missing;
- keeps risky actions behind human approval; and
- can be understood by another person from its workflow card.

If the second run requires rebuilding most instructions, the task may not yet
be stable enough for reuse. That is a useful finding, not a failed course.
