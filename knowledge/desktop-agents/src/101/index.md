# Desktop Agent 101

Complete one useful task with a desktop AI agent, from a safe setup to a
checked result. No coding or command-line experience is required.

## Learning path

1. [Your first useful result](your-first-useful-result.md) - Follow a guided
   lesson using fictional meeting and project notes.
2. [Write a clear task brief](writing-a-clear-task-brief.md) - Tell the agent
   what to make, what it may use, and what “done” means.
3. [Review plans and permissions](reviewing-plans-and-permissions.md) - Keep
   control before the agent acts.
4. [Check the result](checking-the-result.md) - Verify sources, requirements,
   and changes instead of accepting a polished answer on sight.
5. [101 transfer challenge](transfer-challenge.md) - Apply the method to one
   safe task from your own life or work.

Use [Safety and human review](../safety/) throughout this path. If you need a
task idea, choose one from the [scenario library](../scenarios/).
