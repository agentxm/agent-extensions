# Desktop Agent 101 transfer challenge

Use the basic loop on one real but low-risk task from your day-to-day life.
You should complete this challenge without copying the fictional decision-brief
assignment.

## Your challenge

1. Choose a task with two to five inputs and one visible output. Use copies or
   public information.
2. Write a task brief that names the goal, allowed sources, limits, output,
   finish checks, and pause points.
3. Ask for a plan and correct any step that exceeds the brief.
4. Allow the bounded work.
5. Check the output against the brief and at least two source details.
6. Record what changed and whether you would use an agent for this task again.

Keep three pieces of evidence: your brief, the final output, and a short check
note. The check note should identify one thing you verified yourself and one
thing you changed or would change next time.

## Passing evidence

You are ready for 102 when you can:

- explain why this task fit an agent better than chat—or conclude honestly
  that chat was the better choice;
- keep access and actions within the task;
- find and address unsupported or missing content; and
- name a second task where the same loop could transfer.

Do not score time saved from a single attempt as a guaranteed benefit. Setup
and learning take time. Record both the time spent and the handoffs, repeated
copying, or errors the agent removed. Those observations are a better baseline
for deciding what to repeat.
