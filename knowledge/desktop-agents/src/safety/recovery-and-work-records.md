# How to make agent work recoverable

1. Start with copies when learning. Keep the originals outside the agent's
   working folder.
2. Prefer creating a new output over changing the only copy of a file.
3. Before broader edits, confirm that file history, version history, backup,
   or another tested recovery method exists.
4. Ask the agent to list every item it created, changed, moved, deleted, sent,
   or published.
5. Review the actual changes. Do not rely only on the agent's summary.
6. Keep a short work note for important tasks: goal, source set, date, product,
   meaningful decisions, checks performed, and reviewer.
7. If something goes wrong, stop further actions, preserve what happened, and
   recover from a known good copy. Escalate through the relevant workplace or
   service process when data or another person may be affected.

A record is not useful merely because it is long. It should let a future
reader answer: What was the agent asked to do? What did it touch? What did a
person verify? Which version became the accepted result?
