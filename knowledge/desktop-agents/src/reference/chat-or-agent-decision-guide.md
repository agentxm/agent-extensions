# Chat or agent decision guide

Start with the simplest way of working that fits the result.

| If the task mainly needs… | Start with… |
| --- | --- |
| an answer, idea, explanation, or one-off rewrite | Chat |
| several related conversations that should share background or files | A saved project |
| work across files, tools, or connected steps that should end in a changed or new result | A desktop agent |
| sending, publishing, buying, deleting, or changing an account | A draft or plan first, with a person approving the exact outside action |
| regulated, confidential, or high-stakes judgment | Governing policy and a qualified human; use an agent only for a clearly approved supporting role |

Ask these questions:

1. Is the answer itself the result, or must the result be created in my work?
2. Am I repeatedly carrying context or outputs between chat and files?
3. Can I define the workspace and finish line?
4. Can I judge and verify the result?
5. Can mistakes be found and reversed before they matter?

Use chat when it wins these questions. A desktop agent is a better fit only
when its ability to work with the environment removes meaningful handoffs or
supports checks that chat alone cannot.
