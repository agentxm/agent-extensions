# Task brief template

Copy this structure and remove any line that does not help the task.

```text
Goal
Create or change:
This will be used by/for:

Allowed sources and tools
Use these files, folders, websites, or tools:

Boundaries
Do not change:
Do not send, publish, buy, delete, or disclose:
Do not assume:

Output
Create or update:
Required parts:
Format, length, or audience needs:

Finish checks
The result is done when:
Compare or verify it against:

Pause points
Show me the plan before acting.
Stop and ask when:

Closeout
List what you created, changed, moved, deleted, sent, or published.
State remaining uncertainties.
```

For low-risk work, the brief may be one paragraph. Keep the six ideas even
when the wording is shorter: result, sources, protected items, output shape,
checks, and pause points.
