# What a desktop AI agent is

A desktop AI agent is an AI work partner that can operate in a working space
you choose. Depending on the product and the permission you give it, it can
read files, create or change files, use software tools, search approved
sources, and carry a task through several steps.

The important change from ordinary chat is not that the AI sounds smarter. It
is that the AI can work with the same materials and tools that the task uses.
Instead of asking for a draft and then moving every piece yourself, you can ask
for a finished file in a practice folder, inspect how it was made, and request
changes.

The word **agent** is also used for many other things: a customer-service bot,
an automatic background process, a research system, or even a robot. This
guide uses the narrower phrase **desktop AI agent** for a person-directed tool
that works from a computer workspace and reports back to the person.

Three parts matter:

- **A goal:** the result you want, such as a meeting brief or study guide.
- **A working space:** the files, folders, websites, and tools the agent may
  use.
- **Human control:** the person sets limits, approves risky actions, checks the
  result, and owns the final decision.

An agent is not automatically accurate, safe, or independent. Access is not
the same as judgment. A useful agent makes work easier to inspect and improve;
it does not remove the need to think.

For a broader view of why this kind of tool may become useful across many jobs,
