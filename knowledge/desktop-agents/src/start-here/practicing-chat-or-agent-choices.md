# Practice choosing chat or an agent

For each case, choose **chat**, **saved project**, **desktop agent**, or
**human-led route**. More than one may be usable; choose the simplest safe
starting point and write one reason.

1. Explain the difference between simple and compound interest.
2. Combine four fictional household schedules into one conflict list.
3. Keep several months of language-learning conversations and reference files
   together.
4. Draft and send a contract-change email to a real client.
5. Diagnose a patient from symptoms and select treatment.
6. Rename copies of 40 public event photos using a stated naming rule.
7. Brainstorm themes for a retirement party.
8. Turn the same set of weekly team notes into a checked update every Friday.

## Compare your reasoning

1. **Chat:** The answer is the result; no file work is needed.
2. **Desktop agent:** Several files must be read and one result created. Use
   fictional details and check every conflict.
3. **Saved project:** The main need is continuity across related
   conversations. An agent may be added later if file actions are needed.
4. **Desktop agent for the draft, human-led for sending:** A person must review
   the contract facts, audience, and exact outside action.
5. **Human-led route:** Diagnosis and treatment require qualified clinical
   judgment. An approved agent may support a narrower research or organization
   task.
6. **Desktop agent:** Repeated file actions fit, but work on copies and review
   the proposed names before applying them.
7. **Chat:** Brainstorming does not need workspace access.
8. **Desktop agent, then 102 reuse:** File work and checks recur. Observe the
   task before packaging the stable method.

The important skill is not matching these labels word for word. It is
explaining the result, work, risk, and human control behind your choice.
