# Ways desktop agents come packaged

The same agent may be available in more than one form.

| Form | What it feels like | Often works well for | Watch for |
| --- | --- | --- | --- |
| Desktop app | A visual workspace with chats, files, previews, and controls | Documents, research, data, presentations, and mixed work | Which folders, apps, or accounts it can reach |
| Editor add-on | An assistant beside the files open in an editor | Writing, analysis, and software work tied to a set of files | Changes spread across files that are easy to miss |
| Command line | A text session started inside a folder | Precise file work, repeatable steps, and software tools | Unfamiliar commands and broad permissions |
| Browser or cloud worker | A task runs away from the local computer and returns results | Long jobs, parallel work, or work that should continue while you do something else | Where the files run, what was uploaded, and how results return |
| Mixed form | Local and cloud work can be handed back and forth | Work that benefits from both direct local access and background time | Which copy is current and which environment performed the work |

**Local** does not always mean that all AI processing stays on your computer.
**Cloud** does not always mean the agent has unrestricted access to your
accounts. Read the product's current data, permission, and security information
instead of guessing from the interface.

Choose the form that makes the work visible and reviewable for you. A graphical
app may be the easiest first step for a nontechnical learner. A command-line or
editor form can be a better fit when the work already lives there. The learning
method in this bundle is the same for each form.
