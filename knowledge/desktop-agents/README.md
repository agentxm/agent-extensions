# Desktop AI agents

This Knowledge bundle helps people who already use AI chat learn how desktop
AI agents can work with files and tools to complete useful, reviewable tasks.
It includes three learning levels, a shared safety path, fictional scenarios,
templates, assessments, and adaptation guidance.

The curriculum is written in plain language and does not require a particular
AI product or extension manager. Product-specific setup details are isolated
in a short, freshness-dated section.

## Use this bundle when

- learners repeat context or copy results between chat and their work;
- a team needs a safe first experience with a desktop agent;
- an educator needs source material for a workshop, course, or quickstart; or
- reusable AI-assisted work has become difficult to share or maintain.

Do not use it as a substitute for organizational policy, professional
standards, or legal, medical, financial, or pastoral judgment.

## Install

```bash
axm install @agentxm/knowledge/desktop-agents
```

Open `src/index.md` to choose a learning path, or search the bundle for a task,
persona, or safety concern.
