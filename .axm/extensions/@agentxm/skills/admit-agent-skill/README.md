# Admit an Agent Skill

Makes an independent, portfolio-aware decision about whether an exact new or
revised Agent Skill should enter a governed library, remain experimental,
extend or consolidate existing capabilities, be revised, or be rejected.

Use it after authoring, evaluation, and audit evidence exist. It does not modify,
install, publish, or self-approve the candidate.

## Install

This skill depends on shared governance knowledge and is installed through its
pack:

```sh
axm install @agentxm/packs/skill-engineering
```

## Example

Ask an agent to decide whether a proposed deployment-review skill should be
admitted, folded into an existing release-review skill, or returned for revision.
