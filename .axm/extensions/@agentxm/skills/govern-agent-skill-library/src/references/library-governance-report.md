# Agent Skill library governance report

## Assessment identity

- Catalog and source authority
- Snapshot or revision and assessment time
- Policy version and telemetry window
- Included owners, cohorts, hosts, models, and exclusions

## Executive status

Use one portfolio status, then list urgent containment and the most material
systemic findings without collapsing dimension results into one score.

## Inventory reconciliation

Record canonical skills, active versions, lifecycle states, owners,
dependencies, cohorts, deployments, governance records, and authority conflicts.

## Findings by dimension

For admission, stewardship, capabilities, lifecycle, coherence, evidence, and
utility, record observation, evidence, consequence, scope, responsible
authority, required action, and verification condition.

## Control coverage and trends

Report separate measures for ownership, evidence freshness, collision and
selection behavior, risk exceptions, lifecycle skew, and qualified utility.

## Routed actions

Separate containment, admission or reapproval, owner acceptance, evaluation,
audit, authoring, consolidation study, migration, and retirement decisions.
Name unresolved evidence and the next assessment trigger.
