# Governance

Govern a shared skill library through automated evidence, explicit human
authority, enforceable capability limits, and recurring portfolio decisions.

- [Skill library governance model](governance-model.md) - How automation, distributed ownership, independent review, and runtime enforcement govern a skill library without centralizing every decision.
- [Skill governance record](governance-record.md) - The authored claims, independent decisions, runtime facts, and evidence identities needed to govern one skill over time.
- [Admission and ownership](admission-and-ownership.md) - How to decide whether a skill should enter or change the library and who accepts its continuing obligations.
- [Capability boundaries and risk tiers](capability-boundaries-and-risk-tiers.md) - How declared, approved, effective, and observed authority determine controls and reviewers for a skill.
- [Versioning, deprecation, and change control](versioning-deprecation-and-change-control.md) - How a skill's public contract drives semantic versions, reapproval, migration, deprecation, revocation, and retirement.
- [Portfolio coherence and observability](portfolio-coherence-and-observability.md) - How event-driven and periodic controls keep a large catalog owned, distinct, useful, current, and safely exposed.
