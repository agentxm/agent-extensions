# Platforms

Start with the portable Agent Skills contract, then open only the host profile
that constrains the current task. Profiles describe deltas, not replacement
standards, and must be refreshed as host behavior changes.

- [Portable Agent Skills core](portable-agent-skills-core.md) - The cross-host package and progressive-disclosure contract defined by the open specification.
- [OpenAI skill profile](openai.md) - OpenAI-specific discovery, invocation, metadata, and distribution behavior layered on the portable core.
- [Claude skill profile](claude.md) - Claude-specific authoring, evaluation, runtime, and enterprise review guidance layered on the portable core.
- [GitHub Copilot and VS Code skill profile](copilot.md) - Copilot-specific locations, invocation controls, forked context, and plugin behavior layered on the portable core.
- [Gemini CLI skill profile](gemini-cli.md) - Gemini CLI discovery tiers, consent, management, and extension behavior layered on the portable core.
- [AXM skill profile](axm.md) - AXM canonical packaging, projections, manifests, packs, validation, and integrity behavior layered on the portable core.
